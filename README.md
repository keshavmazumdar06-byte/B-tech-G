# B-tech-G
🚆 Train Booking System (C Language)
📌 Project Description

This project is a console-based Train Booking System developed using the C programming language.
It allows users to view available trains, select a train, book seats, and enter passenger details.
The system validates user input and confirms bookings by displaying ticket information.

This project demonstrates the practical use of structures, arrays, functions, loops, and conditional statements in C.



🎯 Why This Project Was Created

The main purpose of creating this project is to:

Understand real-life application of C programming concepts
Practice structured programming
Learn how to manage data using structures
Implement user interaction in a console application
This project was developed as part of an academic practical / mini project.


🛠️ Technologies Used

Programming Language: C
Compiler: GCC / Turbo C / Code::Blocks
Platform: Windows / Linux (Terminal-based)


⚙️ Features / Utility of the Project

Displays a list of available trains
Allows users to select train by train number
Checks seat availability
Accepts multiple passenger details
Confirms booking and displays ticket summary
Prevents invalid inputs (wrong train number, excess seats)

This system can be useful as:
A basic railway booking simulation
A learning reference project for C beginners
A foundation for more advanced booking systems


🧠 Concepts Used

Structures (struct)
Arrays
Functions
Loops (for)
Conditional statements (if-else)
String handling (fgets, strcspn)
Input validation
